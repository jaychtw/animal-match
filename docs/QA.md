## Release status and blockers

CI and Pages workflows are configured for this repository. Pages builds on main pushes or manual dispatch, repeats tests, deploys dist, then checks public HTTP/asset hashes and actual desktop/touch gameplay. Hosted success and public deployment must be independently verified.

The existing GitHub HTTPS proxy successfully reads the repositories. `gh api repos/jaychtw/animal-match` returned Forbidden for api.github.com; no raw token is requested or extracted. Firefox installation returned HTTP 403 Domain forbidden from cdn.playwright.dev and playwright.download.prss.microsoft.com. Required domains (plus jaychtw.github.io for public verification), install_script and start_skill have been saved in the cloud environment draft. Saving does not apply network changes or publish. Review/save these in environment settings, then publish the cloud environment when appropriate. Repository Pages publication is a separate operation.

Source push, exact release commit, local live-verifier results and final browser totals are recorded in `evidence/verification.json`. Never interpret configured workflows or local verification as hosted success.
